# MindPin

Save the locations and notes people share with you, organized by person, and find them again in seconds.

This repo is built spec-first with Claude Code.

- Spec: `docs/spec/requirements.md`, `docs/spec/design.md`, `docs/spec/tasks.md`
- Claude Code instructions: `CLAUDE.md`
- Figma connection: `.mcp.json`

## Start building

1. Install Claude Code, open a terminal in this folder, and run `claude`.
2. Approve the Figma server when asked, then run `/mcp` and authenticate with the Figma account that holds the MindPin designs.
3. Type `/next-task` to begin with task 1.
